﻿﻿﻿﻿本文件是 AI 在本目录工作的**唯一格式规范**，目录内所有小说推文的生成、修改、整理都必须遵守本规范。

## 文件组织规范

- 按题材大类划分题材子目录，如仙侠、科幻
- `书名/书名.md`，一本书对应一个书目录，放入题材子目录
- `书名/书名.txt`，可以获取的免费章节，默认只获取前三章
- `索引.md`，在根目录，维护树形结构书单总表，只收录书籍相关目录
- 所有中间结果文件放入`tmp`目录

### 书名.md格式

```markdown
## 基本信息
- 书名：示例书名
- 作者：示例作者
- 平台：某番茄
- 字数：1234
- 状态：完结
- 题材标签：1v1|纯爱
## 内容简介
（复制来源媒体文件上的简介）
## 笔者评语
（默认为【无】，等待后续填充）
## 元数据
- 整理日期：xxxx-xx-xx
- 整理来源：贴吧
- 链接（如有）：贴吧帖子链接
```

### 书名.txt格式

```
【第一章】章节名
章节内容
【第e章】章节名
```

### 索引.md格式

```shell
变嫁推文整理
├──古风/  (6)
│   ├──天魔大人不会轻易妥协！/
│   ├──我不想要这样实现人妖和谐呀！/

│   └──被迫成为夫人后，今日也郁郁寡欢/
```



## 工作流程

```flowchart LR
A[接收推文来源链接/文件] --> B[解析推文内容为文本，优先使用后文提到的技能]
B --> C[列出全部书名清单]
C --> D[按书名逐本依据规范录入信息，没有的信息使用技能查询]
D --> E[自检]
```

## 完成自检清单

写完后逐项核对，全部通过才结束

* [ ] 格式规范、齐全且可查证（含标签、元数据）
* [ ] 文件命名符合 `书名.md` 规范
* [ ] 书的类型符合题材子目录
* [ ] 新增或有变动的书已同步更新索引
