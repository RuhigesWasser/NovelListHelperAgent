LLM 多模态 API

可选

选择请求协议并保存配置。API 测试和图片能力测试会向所选服务发送少量测试请求。

配置保存在 .local/settings.json。勾选保存密钥时为本地明文；取消勾选则密钥仅供本次运行使用。

高级请求配置

完整 URL 支持 api-version 等查询参数。认证信息使用 API Key 字段；附加参数不能覆盖消息、图片或模型。

ESJ 登录配置

勾选后以明文保存在本目录 .local/esj-settings.json；不勾选则仅本次运行使用。Cookie 始终只保存在内存中。

密码不回显，留空可沿用当前账号已保存的密码。停止应用或退出登录后清除会话，已保存的账号配置保留；也可运行 ESJLogin.cmd 临时登录。

未登录或账号权限不足时，可能无法获取部分小说的详情、目录和正文。

ESJ 读取较慢：先尝试直连，连接失败后使用已配置的系统代理，请耐心等待。

错误恢复

使用当前 LLM 配置，仅在失败或未匹配时调用。生成预算可能包含思考与最终输出，具体取决于接口；新配置默认 32768，旧设置保留，请按模型能力调整。文本模式发送相关 OCR 文字；重新识图模式还会发送原图，启用时验证图片能力。调用次数按任务累计，重试不重置。

可选 OCR 模型

按需下载到本目录。专用模型只重识别对应语言，不自动替换中文结果。
