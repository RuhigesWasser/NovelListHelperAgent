# 使用指南

## 识别与归档

支持帖子链接、单张或多张图片及图片目录。内置 OCR 在本机运行；多模态模式会向选定服务发送图片。

任务可在识别后自动提取、核对并归档。关闭浏览器不停止后台服务；任务列表可取消、继续或恢复失败项。识别结果支持校对和 JSON 导出。

书名与作者均匹配时可以自动确认。作者缺失、标题被截断或候选冲突时，条目留待核对，并显示原因与原帖楼层链接。书架截图可以产生多个条目；正文评论保留供查阅，不会将每句话都当作书名。

## 浏览书库

书库支持按书名、作者或标签搜索，以及分类、平台、状态筛选和排序。点击书名或“查看详情”查看完整简介、来源和评语；“编辑资料”修改已保存信息，书名和分类路径保持不变。

已有正文的书籍可直接在窗口中阅读或导出。添加新书请使用“添加书籍”，可以查询官方资料或手动填写。编辑时若书籍已被其他操作更新，会提示重新打开详情，避免覆盖较新的修改。

## 封面

通过官方查询归档的书籍会后台缓存可用封面；旧书可点击“补全封面”。图片保存在各书籍目录中，之后从本机加载，可离线查看。

详情中可获取、刷新或上传封面。支持不超过 8 MB 的 JPG、PNG、WebP 和 GIF，上传后转为适合显示的静态图片。自动刷新不会覆盖手动封面；“恢复平台封面”会重新获取官方图片。获取失败保留已有封面，不影响书籍资料和正文。

番茄的签名图片地址过期后会重新读取书籍详情；起点优先使用页面提供的高清图。ESJ 的图片可能来自外部图床，访问情况与小说正文不同。封面下载使用本机网络配置，不向图床发送账号 Cookie。

## 平台与章节

支持起点、刺猬猫、菠萝包、番茄和 ESJ 的候选搜索与详情补全。

- 起点使用官方移动页读取资料及公开免费章节。
- 刺猬猫支持搜索、详情和目录；部分阅读页要求网页验证或登录。
- ESJ 部分作品的详情、目录和正文需要登录及站点权限，读取较慢；直连失败后会尝试已配置的系统代理。
- 各平台均可从书籍详情选择要下载的目录条目，支持按标题筛选、选择未下载条目和批量下载。默认建议前三项，可自行增减；设定集、番外不一定是正文起点。关闭选章窗口会在当前章节完成后停止。

获取成功后生成同目录的 `.txt` 和章节来源记录。重复下载会更新对应章节，保留其他已保存章节。阅读页提供章节目录、上一章和下一章，并记住上次阅读的章节。旧版已保存正文也可直接打开。没有取得正文时显示错误；失败刷新不会覆盖已有正文。

## LLM 配置

设置页可保存多份命名配置，并记住最后选择。支持 Chat Completions、Responses、Anthropic、Gemini、Ollama；可使用标准基础地址或完整接口 URL。

API Key 填入专用字段。勾选保存密钥时以明文写入 `.local/settings.json`；取消勾选则密钥仅保留在服务内存中。已保存密钥不回显，留空沿用原值。删除配置或清除密钥可移除磁盘中的密钥。

“测试 API 调用”验证模型能否响应；“测试图片能力”验证图片是否被正确读取，两者不能互相替代。测试可能消耗服务额度。

新配置默认生成预算 32768 token、超时 300 秒，已有配置保持原值。推理模型可能将思考和最终输出共用预算。Chat Completions 可选择 max_tokens 或 max_completion_tokens；上限及附加生成参数须符合所用服务要求。流式中断、拒绝响应和输出截断会显示错误。

## ESJ 账号

设置页可登录 ESJ。勾选“保存账号和密码”时以明文保存到 `.local/esj-settings.json`，否则仅本次运行使用。Cookie 始终只放内存。清除账号会移除保存的凭据并退出登录；账号权限不足仍可能无法读取作品。

## 错误恢复

可选择关闭模型兜底、文本兜底或文本加重新识图。文本模式发送相关 OCR 文字，重新识图还会发送原图；使用当前 LLM 配置。默认每任务最多调用三次，每次预算 32768 token，可在设置中调整。调用次数累计，重试不重置。

恢复可以修复书单 JSON、调整查询和重新识别失败图片。更正结果仍需官方资料核对。已成功的单图 OCR 结果会保留，局部恢复不必重新抓取整个帖子。

## 数据与卸载

`.runtime` 保存私有 Python、依赖、模型和下载缓存；`.local` 保存任务、素材、配置、日志和书库。先停止应用，再运行 Clean 入口清理，或删除完整应用目录。需要保留的书库与凭据应先备份。

应用不修改系统 PATH，不注册开机启动。浏览器历史、操作系统记录和导出到其他位置的文件需在对应位置管理。

## 网络连接

平台资料、封面、素材图片、模型下载和 LLM 请求优先直连。连接失败或服务器暂时不可用时，才尝试已配置的系统代理；不修改系统代理设置。认证失败、无权限和限流会直接显示原错误。
